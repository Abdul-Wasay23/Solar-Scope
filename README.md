# SolarScope

SolarScope is a web-based solar planning, visualization, estimation, and marketplace project.

## Versions
- V1: Module 2 completed version.
- V2: Module 3 development version.
- V3: Separate working copy for further development.

## Project Structure
- v1/ - Module 2 version
- v2/ - Module 3 development version
- v3/ - New development version

## Running
Open a terminal inside the required version folder and run:
npm install
npm run dev

Do not upload real .env files, passwords, tokens, or API secrets.
